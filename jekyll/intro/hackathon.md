## 대회 개요

| 구분 | 내용 |
|---|---|
| 행사명 | 2026년 제8회 K-디지털 트레이닝 해커톤 |
| 목적 | K-디지털 트레이닝 훈련생 대상 해커톤을 개최하여, 훈련생의 첨단·디지털 분야 실무 역량 제고 및 공익적 아이디어 발휘의 장 마련 |
| 주제 | **AI와 함께, 인간의 가능성을 확장하다** (지정/자유과제 택1) |
| 참가 대상 | K-디지털 트레이닝 훈련생 또는 수료생으로 구성된 팀 (팀당 3명~6명) |
| 유의사항 | 기존 K-디지털 트레이닝 해커톤 대회 수상자는 참가 불가 |
| 예선 | 서류(기획서) 제출 마감 8/10 → 결과 발표 8/21 (본선 진출 확정) |
| 본선 | **9/2 대회** — 최종 결과물 제출 (개발 마감 9/1) |

## 과제 유형

1. **지정과제**: AI 전환 시대, 인간의 역량을 확장하는 디지털 서비스 개발
2. **자유과제**: 첨단·디지털 기술을 활용한 창의적 서비스 개발

## 우리 팀의 선택

- **지정과제** — 라이프 튜토리얼은 AI(법령 원문 RAG + LLM 시뮬레이션)로 사회초년생의 법률 대응 역량을 '확장'하는 서비스로, 지정과제 취지에 부합합니다.
