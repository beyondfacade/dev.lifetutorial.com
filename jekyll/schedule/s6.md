**기간**: 9/1 ~ 9/2


**상태**: ✅ **완료** — 프로덕션 배포·개발 마감(지연·크래시 제거)·라이선스 정리에 이어 본선 대회까지 끝났다. 결과는 🏆 **우수상(고용노동부장관상) 수상(9/4)**.

**스프린트 목표**: 개발 마감, 최종 결과물 제출, 발표 및 실제 플레이 시연.

| 일자 | 담당 | 업무 내용 | 상태 |
|---|---|---|---|
| 9/1 | 김충식 | 최종 결과물 패키징 — 제출물 점검, 발표자료 최종본 | ✅ 완료 — 제출물은 **실도메인 배포로 갈음**한다. 별도 빌드 산출물을 넘기는 대신 심사위원이 `www.life-tutorial.com`에서 브라우저로 직접 플레이하는 형태(8/31 배포·실도메인 로그인 왕복 확인) . 발표자료 최종본도 완성했고, 네트워크 사고 대비로 시연 영상 녹화 — 유튜브에 전체 완주 롱폼 1편 + 기능별 숏폼 4편(방어전 · 주휴수당 계산 · OCR 문서 점검 · 상담 준비 리포트, 링크는 [프로젝트 개요 → 시연 영상]({{ "/docs/overview.html#demo-videos" | relative_url }})) |
| 9/1 | 이은상 | 백엔드 안정화 — Fake↔실LLM 전환 스위치 최종 점검 | ✅ 완료 — 임베딩 429 고정 대기를 지수 백오프로 교체(방어전 턴 28초 → 중앙값 0.4초), OCR 입력 상한으로 업로드 OOM 차단(12MP → peak 1.33GB, 9/2 릴리스 반영 BE v0.16.30 — 문서 점검 테스트 71개 전량 통과), 8/31 CORS·쿠키·OAuth 반영·동시 슬롯 1 확정 / 8/29 폴백 훈련 절차 결함(오프라인 전환 시 리포트 모델 언로드) 반영은 잔여 |
| 9/1 | 신채연 | 프론트 최종 빌드 — 시연 기기 세팅 확인 | ✅ 완료 — 8/31 프로덕션 빌드 Vercel 배포(첫 로드 9.5MB→1.43MB), 9/1 상담 준비 리포트 PDF 인쇄 수정(FE v0.33.11), 9/2 라이선스 고지 페이지 `/licenses` + 재배포 금지 에셋 히스토리 제거(82커밋 재작성) 후 프리빌드 재배포(FE v0.34.0) |
| **9/4** | 전원 | **해커톤 대회 — 발표 + 실제 플레이 시연, 최종 결과물 제출** | ✅ 완료 — 🏆 **우수상(고용노동부장관상) 수상** |

**본선 1일차 잔여 (9/1 기준)**: 외부망(집 와이파이 밖) 실동작 확인, 긴 요청(상담 준비 리포트 ~30초) 터널 통과 확인, OCR 입력 상한 커밋·버전 로그 반영(→ 9/2 BE v0.16.30으로 완료) 후 실제 폰 사진 왕복 재확인.
